dxf-viewer 수정 내용 (MPL-2.0)

Easy Open은 dxf-viewer(Mozilla Public License 2.0)를 three.js와 함께 하나의 파일로 묶어 사용합니다. 묶은 파일: dxf/dxf-viewer.bundle.js

묶는 방법

// entry.js
import { DxfViewer } from 'dxf-viewer';
import * as THREE from 'three';
window.DxfViewer = DxfViewer;
window.THREE = THREE;

npx esbuild entry.js --bundle --minify --outfile=dxf-viewer.bundle.js

원본에서 바꾼 곳 (1곳)

파일: src/DxfScene.js, 도형 색을 정하는 함수(_GetEntityColor). 색이 BYLAYER(색 번호 256)로 적힌 도형이 레이어 "0"에 있으면, 자기 레이어 색을 바로 쓰지 않고 원본의 BYLAYER 지연 처리(블록 안에서는 블록을 넣은 레이어의 색을 따름)에 맡기도록 조건을 하나 더했습니다.
